# Cascade Workspace — HFT Trading System

Эта папка — рабочее пространство Cascade AI для проекта HFT Trading System.

## Структура

```
.cascade/
├── README.md              — этот файл
├── tasks/                 — ТЗ от пользователя (клади сюда .md файлы)
├── workflows/             — воркфлоу для AI
│   ├── ai-monster-workflow.md   — полный автономный workflow (закон)
│   ├── deep-scan.md             — промпт для глубокого сканирования кода
│   ├── project-analysis.md      — промпт для анализа структуры проекта
│   ├── update-docs.md           — промпт для обновления документации и планирования
│   └── fix-bugs.md              — workflow для фикса багов и реализации фич
├── progress.md            — журнал выполненных задач и коммитов
├── notes.md               — заметки, контекст, полезные ссылки
├── bug_log.md             — лог найденных багов
├── file_tracker.md        — трекер просмотренных файлов
└── proposals/             — предложения по улучшению
```

## Workflow

1. Пользователь кладёт ТЗ в `tasks/` (или воркфлоу в `workflows/`)
2. Cascade читает ТЗ и подходящий воркфлоу
3. Cascade проверяет/исправляет/разрабатывает
4. Cascade коммитит изменения (АВТОКОММИТ — после каждого изменения)
5. Cascade отмечает прогресс в `progress.md`

## Правила

- Один ТЗ = один `.md` файл в `tasks/`
- Имя файла: `NNN_краткое_описание.md` (например `001_add_garch.md`)
- После выполнения — отметить в `progress.md` с хэшем коммита
- **АВТОКОММИТ** — после КАЖДОГО изменения в коде. Без исключений.
- **ЧЕСТНОСТЬ** — не врать в документации. Если чего-то нет — писать что нет.

| Файл | Назначение |

| `ai-monster-workflow.md` | Полный автономный workflow — закон для AI |

| `fix-bugs.md` | Workflow: фикс багов из MASTER_DEVELOPMENT_PLAN.md |
