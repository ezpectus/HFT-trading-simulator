## Workflow файлы (в .windsurf/workflows/)

| Файл | Назначение |
|------|------------|
| `code-review.md` | AI агент B проверяет код агента A по ТЗ |
| `module-split.md` | Шаблон разделения модулей (model + funcs + facade) |

## Как использовать

### Для пользователя
1. **Открой `context_cache.md`** — пойми текущее состояние проекта
2. **Открой `office-board.md`** — посмотри задачи на сегодня
3. **Скажи AI что делать** — или дай команду `/code-review` для проверки

### Для AI (само-оркестрация)
1. Прочитай `context_cache.md` — определи текущий день плана
2. Прочитай `office-board.md` — определи задачу
3. Выполни задачу → запусти `/code-review` → обнови `progress.md`
4. Обнови `context_cache.md` в конце дня

## Абсолютные правила

- **ТОЛЬКО IDE** — терминал запрещён (кроме git commit/push)
- **КАЧЕСТВО КОДА** — нет AI slop, функция ≤40 строк, 0 дублирования, type hints
- **ТЕСТЫ** — все существующие тесты должны проходить после каждого изменения
- **ДОКУМЕНТАЦИЯ** — progress.md после каждого изменения
- **ЧЕСТНОСТЬ** — не врать в документации
- **ПЛАН** — `docs/REFACTORING_PLAN_10DAYS.md` — главный драйвер на 10 дней
