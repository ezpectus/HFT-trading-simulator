### 1.2. Продвинутые типы ордеров

**Conditional Orders**
- **Описание:** Ордера которые исполняются только при выполнении условия (цена > X, объём > Y, время > Z)
- **Причина:** Более реалистичная симуляция, поддержка продвинутых стратегий
- **Приоритет:** Средний
- **Сложность:** Средняя
- **Оценка времени:** 3 дня
- **Зависимости:** Нет
- **Примечания:** Нужно реализовать парсер условий

**Post-Only Orders**
- **Описание:** Ордера которые только добавляют ликвидность (maker only), отклоняются если пересекают стакан
- **Причина:** Более реалистичная симуляция, поддержка maker-only стратегий
- **Приоритет:** Средний
- **Сложность:** Низкая
- **Оценка времени:** 2 дня
- **Зависимости:** Нет
- **Примечания:** Простая реализация

**Iceberg Orders**
- **Описание:** Скрытые ордера которые показывают только часть объёма
- **Причина:** Более реалистичная симуляция, поддержка крупных трейдеров
- **Приоритет:** Низкий
- **Сложность:** Средняя
- **Оценка времени:** 3 дня
- **Зависимости:** Нет
- **Примечания:** Нужно реализовать логику скрытия части объёма

**TWAP (Time-Weighted Average Price) Orders**
- **Описание:** Ордера которые исполняются равномерно во времени
- **Причина:** Более реалистичная симуляция, поддержка алгоритмической торговли
- **Приоритет:** Низкий
- **Сложность:** Средняя
- **Оценка времени:** 1 неделя
- **Зависимости:** Нет
- **Примечания:** Нужно реализовать планировщик

**VWAP (Volume-Weighted Average Price) Orders**
- **Описание:** Ордера которые исполняются по средневзвешенной цене объёма
- **Причина:** Более реалистичная симуляция, поддержка алгоритмической торговли
- **Приоритет:** Низкий
- **Сложность:** Средняя
- **Оценка времени:** 1 неделя
- **Зависимости:** Нет
- **Примечания:** Нужно отслеживать объём сделок

### 1.3. Моделирование влияния на рынок

**Market Impact Model**
- **Описание:** Модель оценки влияния крупных ордеров на цену (Almgren-Chriss model)
- **Причина:** Более реалистичная симуляция, поддержка крупных трейдеров
- **Приоритет:** Средний
- **Сложность:** Средняя
- **Оценка времени:** 1 неделя
- **Зависимости:** Нет
- **Примечания:** Формула: impact = gamma * (order_size / avg_daily_volume)^(1/2)

**Slippage Model Enhancement**
- **Описание:** Улучшенная модель проскальзывания с учётом волатильности, объёма, спреда
- **Причина:** Более реалистичная симуляция
- **Приоритет:** Средний
- **Сложность:** Низкая
- **Оценка времени:** 3 дня
- **Зависимости:** Нет
- **Примечания:** Нужно добавить факторы волатильности и объёма

**Liquidity Depth Model**
- **Описание:** Модель глубины ликвидности на разных уровнях цены
- **Причина:** Более реалистичная симуляция order book
- **Приоритет:** Низкий
- **Сложность:** Средняя
- **Оценка времени:** 1 неделя
- **Зависимости:** Нет
- **Примечания:** Можно использовать лог-нормальное распределение
